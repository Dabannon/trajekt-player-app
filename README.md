# Trajekt Player App

Next.js app for the Trajekt player prototype (occlusion training + home).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Single route (`/`) renders the responsive `PlayerApp` from the original DC prototype.
- Media lives in `public/assets`.
- Prototype source HTML/JSX remains in the repo root for reference; the running app uses `components/` and `app/`.
